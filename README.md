# 혈당 도우미 (blood-sugar-monitor)

당화혈색소 5.9%(당뇨병 전단계 범위)인 부모님의 식사와 운동 관리를 돕는 웹앱입니다.

- 계획서: [PLAN.md](PLAN.md)
- 현재 단계: **M1 — 앱 뼈대와 자동 검사** (의학 수치를 계산하는 기능은 아직 없습니다)

## 원칙

- 이 앱은 **의료기기가 아니며** 진단이나 치료를 대신하지 않습니다.
- 영양소 숫자는 **식약처 공식 DB나 제품 표기값**만 씁니다. AI는 음식 인식과 양 제안만 합니다.
- 앱의 모든 기준값은 `src/evidence/registry.ts`의 근거 등록부에 출처와 함께 기록합니다. **원문 확인이 끝나지 않은 기준값을 코드에서 쓰면 테스트와 빌드가 실패**합니다.

## 개발 방식 (로컬 PC 사용 없음)

1. 코드는 GitHub에 직접 커밋합니다.
2. GitHub Actions가 타입 검사, 테스트, 빌드를 실행합니다 (`.github/workflows/ci.yml`).
3. (예정) Vercel이 GitHub과 연결되어 커밋마다 미리보기 주소를 만듭니다.

API 키 같은 비밀값은 저장소에 커밋하지 않고 배포 서비스의 환경변수에만 둡니다.

## 명령어 (GitHub Actions와 Vercel이 실행)

| 명령 | 하는 일 |
|---|---|
| `npm run typecheck` | TypeScript 타입 검사 |
| `npm test` | 단위 테스트 (근거 등록부 검사 포함) |
| `npm run build` | 타입 검사 + 테스트 + 배포용 빌드 |
